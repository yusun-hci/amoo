# Amoo · 人格探索工作台

面试用静态交互原型，作者：Yu Sun。奶油、沙色、暖棕视觉参照用户提供的 Amoo 宣传物料。独立概念探索，并非官方产品或授权项目。

## 最快部署到 GitHub Pages（无需命令行）

1. 解压 ZIP，新建一个 GitHub 仓库，如 `amoo-personality-lab`。
2. 点击 **Add file → Upload files**，上传本目录里面的所有文件和 `assets` 文件夹。`index.html` 必须在仓库根目录，不能再嵌套一层同名目录。
3. 提交文件后，打开 **Settings → Pages**。
4. **Build and deployment → Source** 选择 **Deploy from a branch**。
5. Branch 选择 **main**，目录选择 **/(root)**，保存。等待 GitHub 显示部署成功后，打开该页面给出的站点地址。

通常地址形式为 `https://你的用户名.github.io/amoo-personality-lab/`。本包全部使用相对路径，可部署到项目子目录。无 API Key、无后端、无 npm、无构建步骤。此任务只交付源码，不会替你创建仓库或公开发布。

也可以将整个目录推送到 Git 仓库后，按相同设置启用 Pages；没有自动部署 workflow，也不需要 Actions 配置。

## 本地使用

直接双击 `index.html` 即可使用主要功能。剪贴板和分享链接在 HTTPS 站点上效果最好。若有 Python，可在本目录运行 `python -m http.server 8000`，打开 `http://localhost:8000`。

## 功能

- 八个连续滑条，低/中/高阈值影响规则；不是心理学量表。
- 八个角色预设：大白、瓦力、史迪奇、龙猫、史努比、哆啦A梦、伙伴皮卡丘、轻松熊。
- 最近三个参照角色、图片、借鉴机制、借鉴边界；完整 30 角色地图弹窗。
- 五个情境：初见、疲惫回家、忙碌、明确拒绝、重逢与共同记忆。
- 四个反馈按钮：一起玩、安静、停止、回到情境起点。
- 台词、动作意图、后续状态、规则原因及参与参数，简化 SVG 动作示意。
- 关闭记忆后，不调用共同击掌经历。
- A/B 保存、载入、清除；导出 JSON；链接分享参数、情境与记忆开关。
- 当前参数及 A/B 仅保存在当前浏览器 localStorage，不发往服务器。导出文件和分享链接由用户自行保管。
- 响应式布局、键盘滑条、焦点状态、减少动画偏好支持。

## 文件与修改入口

| 文件 | 用途 |
|---|---|
| `index.html` | 页面结构与文案 |
| `styles.css` | 配色、布局、SVG 动画 |
| `data.js` | 八维定义、角色人工标注、图片区域、情境 |
| `engine.js` | 规则选择、语言/动作生成、匹配计算，纯函数 |
| `app.js` | 界面交互、保存、导出、分享 |
| `assets/character-map.png` | 此前生成的角色示意插画 |
| `tests/engine.test.cjs` | 规则边界与组合完整性检查 |
| `DESIGN.md` | 设计逻辑、面试演示与能力边界 |
| `.nojekyll` | 让 GitHub Pages 按静态文件提供内容 |

修改角色参数：编辑 `data.js` 中 `characters[].values`，顺序对应八维。图片目前通过 CSS 从同一张地图中取景，坐标单位对应原图 1672×941。替换图片后同步修改 `crop` 和 `app.js` 中图像尺寸。所有图片已随包附带，不依赖外链。

修改回应：编辑 `engine.js` 的 `respond`。优先级是明确停止 → 安静 → 用户主动同意活动 → 场景起点 → 人格表达。点击“一起玩”视为用户重新发起并同意，因此可以退出此前的安静/拒绝状态。

角色匹配：八维等权欧氏距离排序，只代表本原型中的人工编码，不输出“人格相似百分比”。角色全部是启发式参照，不是心理评估。

## 检查

安装 Node.js 后运行 `node tests/engine.test.cjs`。覆盖 10,240 个端点组合下的情境/反馈/记忆组合，并验证角色预设与输入边界。静态语法可用 `node --check app.js` 等检查。

浏览器人工验收建议：
1. 切换角色、拖动八维，检查台词/动作/参照更新。
2. 将主动性、活力、持续性调至 100，在忙碌和拒绝情境确认停止。
3. 重逢情境关闭记忆，确认不再说记得击掌。
4. 存 A、修改并存 B，刷新、载入、导出。
5. 复制分享地址，用无痕窗口打开；测试手机窄屏、键盘与地图弹窗。
